# Guía arbolaria y biológica del campus

Proyecto web en HTML, CSS y JavaScript separados. Está pensado para que cada árbol tenga un código QR que abra una ficha específica usando el enlace con `#id/seccion`.

## Archivos principales

- `index.html`: estructura de la página.
- `style.css`: diseño visual, animaciones y adaptación a celular.
- `plantas.js`: información de cada árbol o planta, en el orden de la guía.
- `script.js`: navegación tipo presentación y cambio entre fichas.
- `imagenes/`: fotos de referencia.

## Cómo abrirlo

Abre `index.html` en el navegador. No necesitas instalar nada.

## Cómo subirlo a GitHub

1. Crea un repositorio nuevo.
2. Sube todos los archivos de esta carpeta.
3. Activa GitHub Pages desde `Settings > Pages`.
4. Usa la URL publicada para generar los códigos QR.

Ejemplo de enlace para un QR:

`https://tuusuario.github.io/tu-repositorio/#mango/inicio`

Cambia `mango` por el identificador de cada planta, por ejemplo `guayaba`, `caimito` o `roble-sabana`.

## Identificaciones pendientes

Algunos nombres comunes pueden referirse a más de una especie. En esas fichas aparece “por confirmar”. Cuando tengas foto del tronco, hojas, flor o fruto del ejemplar real del campus, se puede ajustar el nombre científico.
